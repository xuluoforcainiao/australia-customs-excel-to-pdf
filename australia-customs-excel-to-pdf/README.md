# australia-customs-excel-to-pdf

Convert Australian customs/ logistics commercial invoice Excel files (.xlsx) into a single-page land

## 安装

使用 GitHub CLI 安装：

```bash
gh skill install xuluoforcainiao/australia-customs-excel-to-pdf australia-customs-excel-to-pdf
```

## 使用

安装后，在 QoderWork 中提及或使用此 skill 时会自动激活。

你也可以通过以下方式手动触发：

```
请使用 australia-customs-excel-to-pdf skill 来帮我...
```
